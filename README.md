# 🎯 Laboratório de JavaScript para QA

## 📚 Sobre este Repositório

Bem-vindo ao meu laboratório de estudos! Este é um espaço dedicado ao aprendizado de **JavaScript** dentro do contexto de **Automação com Playwright** - Módulo 2.

Aqui deixo claro: **não se trata de me tornar desenvolvedor**. O objetivo é dominar o "volante" da automação, aprendendo JavaScript como ferramenta essencial para criar scripts robustos, confiáveis e profissionais de automação de testes.

> 💡 Cada linha de código é um passo em direção ao domínio da automação inteligente.

---

## 🗺️ Tópicos de Estudo

Neste laboratório, vou aprofundar meus conhecimentos nos seguintes temas:

- **📌 Variáveis**
  - Diferenças entre `let` e `const`
  - Escopo e boas práticas

- **🔢 Tipos de Dados**
  - String, Number, Boolean, Object, etc.
  - Conversão e coerção de tipos

- **📦 Arrays**
  - Manipulação, iteração e métodos úteis
  - Aplicações em testes automatizados

- **⚙️ Funções**
  - Declaração, expressão e arrow functions
  - Funções puras e padrões de reuso

- **🔀 Condicionais**
  - If/else, switch cases
  - Lógica booleana eficiente

- **🔄 Loops**
  - for, while, forEach, map, filter
  - Iteração segura e performática

- **⏳ Async/Await** ⭐
  - Promessas e operações assíncronas
  - Essencial para automação com Playwright

## 🧠 Mentalidade

```
"Profissional não confia. Profissional confere."
```

Este princípio norteia toda minha jornada aqui. Em automação de testes, a confiabilidade não é negociável. 
Cada validação, cada espera, cada assertion deve ser pensada com cuidado e verificada rigorosamente.

✅ **Testar** é verificar que o código faz o que promete  
✅ **Debugar** é entender por que não está funcionando  
✅ **Refatorar** é melhorar sem quebrar nada
